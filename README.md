# Deep-Sea Trenches of the Pacific Ocean: Comparative Submarine Geomorphology

LaTeX (Beamer) source of the research presentation **"Deep-Sea Trenches of the
Pacific Ocean: A Comparative Analysis of the Submarine Geomorphology by Data
Modeling Using GMT, QGIS, Python and R"** by Polina Lemenkova.

Presented at **Ocean University of China (OUC), College of Marine Geo-Sciences,
Qingdao, China, on 4 November 2019**.

The talk presents a comparative geomorphometric analysis of the deep-sea trenches
of the Pacific Ocean from bathymetric data, combining cartographic scripting with
the Generic Mapping Tools (GMT), spatial analysis in QGIS, and statistical data
modelling in Python and R.
